# Anvil-Parser-Dungeons-II

Simple parser for the [Minecraft Anvil File Format](https://minecraft.gamepedia.com/Anvil_file_format), in Minecraft 1.18+ - Dungeons II Support

Based on [matcool's anvil-parser](https://github.com/matcool/anvil-parser), all credit goes to them.

Based on [Intergalactyc's anvil-new](https://github.com/Intergalactyc/anvil-new)

# Installation

```
pip install git+https://github.com/SyndiShanX/Anvil-Parser-Dungeons-II.git
```
